# Comprehensive PDF-tool capability reference

Inspected: 2026-09-22

This is a normalized, self-contained description of the tools shown in the supplied screenshots and the pages opened in the internal browser. The source sites often expose the same operation in several categories—for example, “Compress PDF” can appear under Optimize, Frequently used, Last used, or a security-related group. Those occurrences are merged here by capability, but meaningful differences are retained.

`README.md` remains the occurrence-preserving inventory: it keeps every screenshot occurrence and places the corresponding link in front of each item. This document is the feature reference and does not repeat a separate section for every provider.

## How overlapping tools were merged

- The same operation with the same input and output is described once.
- A broader tool is not allowed to erase a narrower one: for example, “Edit PDF” includes text, images, shapes, resize, color, opacity, borders, rotation, and line thickness where those controls were observed.
- Different processing models remain visible: cloud upload, local browser processing, desktop/offline processing, and mobile capture are not treated as interchangeable.
- Distinct output choices remain visible: one combined file, one file per page, a ZIP package, extracted images, editable office files, and archival PDF/A output are separate outcomes.
- Tool labels that appeared in multiple screenshot locations are treated as repeated entries, not as separate products, unless their functionality was actually different.

## 1. Create, capture, and generate documents

### Create or capture a PDF

- Create a PDF from supplied content or files.
- Capture pages with a camera and turn the captures into a PDF.
- Convert a webpage into a PDF.
- Combine one or more images into a PDF.
- Create a fillable PDF form by placing interactive fields.
- Create a PDF job-application document.
- Scan paper pages with a mobile camera and create PDFs.
- Generate a QR code for PDF-related content.

### AI document generation

- Describe an invoice, resume, NDA, survey, or another document and generate a formatted PDF.
- Attach source files to help the generator create the document.
- Start from document templates or use a surprise/random template option.
- Generated content may be inaccurate; legal documents require human/legal review.

## 2. Invoicing and structured business documents

- Create an invoice as a PDF.
- Build an invoice visually with a layout/editor workflow.
- Create an electronic invoice.
- Convert a PDF invoice to an electronic invoice.
- Convert an XML e-invoice to PDF.
- Convert a PDF bank statement into structured Excel or CSV output.
- Use OCR for scanned or image-based bank statements before producing structured data.

## 3. Convert office and structured files to PDF

### Word-processing and text formats

- DOC/DOCX to PDF.
- RTF to PDF.
- TXT/plain text to PDF.
- ODT to PDF.
- Markdown to PDF.
- HTML to PDF, including a webpage-URL workflow with preview and orientation/margin controls.

### Spreadsheet and presentation formats

- XLS/XLSX to PDF, retaining spreadsheet formatting, columns, tables, graphics, and formulas where supported.
- ODS to PDF.
- PPT/PPTX/PPSX to PDF, retaining presentation text, images, and layout.
- ODP to PDF.
- Microsoft Publisher/PUB to PDF.

### Image and graphic formats

- JPG/JPEG to PDF.
- PNG to PDF.
- WEBP to PDF.
- BMP to PDF.
- GIF to PDF; static or animated GIF input may be represented as PDF page content.
- TIFF to PDF.
- HEIC/HEIF to PDF.
- SVG to PDF.
- PSD, AI, and INDD to PDF on the Adobe tool catalog.

### Ebook and archival formats

- EPUB to PDF.
- Convert a regular PDF to PDF/A for long-term archival and preservation.
- PDF/A conversion may embed fonts, remove dynamic elements, and lock visual content to meet archival requirements.

## 4. Convert PDF into editable or reusable documents

### Office documents

- PDF to Word/DOC/DOCX: produce an editable document while attempting to retain text structure, spacing, fonts, and layout.
- PDF to PowerPoint/PPTX: produce editable slides; multi-page PDFs can become one slide per page, with text, graphics, and images transferred.
- PDF to Excel/XLSX: extract tables, spreadsheet-like data, graphs, and structured content into an editable workbook.
- PDF to ODT: convert to OpenDocument text.
- PDF to ODS: convert to OpenDocument spreadsheet.
- PDF to ODP: convert to OpenDocument presentation.
- PDF to RTF: produce Rich Text Format content.
- PDF to TXT/Text: strip the document down to extractable text.
- PDF to HTML: create web-ready HTML; core text flow, headings, tables, and layout structure may be retained even when complex design elements are not.
- PDF to Markdown: turn PDF content into Markdown.
- PDF to EPUB: turn PDF content into an ebook.
- PDF to CSV: extract structured table data into CSV for spreadsheet and data-analysis workflows.

### Specialized reuse

- Extract embedded images from a PDF.
- Turn PDF pages into reusable image files.
- Extract text with OCR when the source is scanned or image-based.

## 5. Convert images and PDF pages

### PDF to image

- PDF to JPG/JPEG.
- PDF to PNG.
- PDF to BMP.
- PDF to GIF.
- PDF to TIFF.
- PDF to SVG.
- PDF to a general image set.
- Convert one page or the entire document.
- Download images individually or together in a ZIP archive where supported.
- Extract the original pictures from a PDF as a separate ZIP rather than rendering every page.

### Image-to-PDF differences retained

- JPG-to-PDF tools commonly expose portrait/landscape selection, margins/no margins, and image merging.
- PNG/BMP/TIFF/HEIC tools focus on preserving image quality and combining multiple images.
- HEIC/HEIF tools are useful for iPhone photos and print-ready/shareable PDFs.
- GIF-to-PDF tools can handle still or animated GIF input, while PDF-to-GIF output is static page imagery.
- Some local-browser image converters advertise no watermark, no account, no file-size cap, and offline use after the page loads.

## 6. Merge, split, extract, and assemble documents

### Merge

- Combine multiple PDFs into a single document.
- Reorder files or pages before merging.
- Merge several password-protected PDFs when the service supports it.
- Some services can merge office files and images by converting them as part of the same workflow.

### Split

- Split a PDF into separate files.
- Split by selected page ranges.
- Extract every page as its own PDF.
- Merge selected ranges back into one output PDF.
- Split repeatedly or batch-process multiple inputs.
- Download the resulting parts individually or as a ZIP package.

### Extract pages

- Select individual pages, page ranges, or complete sections.
- Preview page thumbnails before extraction.
- Create one combined output PDF or one separate file per selection.
- Leave the original file unchanged.
- Convert extracted pages to JPG, Word, PowerPoint, or other supported formats.

### Delete pages

- Preview thumbnails and mark pages for removal.
- Delete one or more pages from one or multiple PDFs.
- Use the red-cross/marked-thumbnail workflow shown by the iLovePDF documentation.
- Export the remaining pages as a new PDF.

## 7. Reorder, rotate, and change page layout

- Rearrange, sort, shuffle, duplicate, or reorder pages by drag-and-drop.
- Rotate a single page, selected pages, an entire PDF, or multiple files in one operation.
- Rotate files automatically when more than ten files are selected where supported.
- Change PDF page size.
- Place multiple PDF pages on one sheet/page.
- Halve PDF pages into separate page areas.
- Crop page boundaries or selected areas by dragging a crop region.
- Crop one page or apply the crop to all pages.
- Add page numbers to all pages, facing pages, a chosen page range, or selected pages.
- Configure page-number position, margins, font/typeface, size, color, opacity, and numbering format.
- Add repeating headers and footers at left, center, or right positions.
- Insert recurring titles, dates, page numbers, and document references into headers/footers.
- Use header/footer templates and apply them to all or selected pages.

## 8. Edit, annotate, fill, and brand PDFs

### Direct editing

- Edit existing text directly while attempting to preserve the original font.
- Add new text and customize font, size, color, placement, and dimensions.
- Add images, logos, photos, and graphics.
- Resize, move, rotate, and position added objects.
- Add shapes and adjust their color, transparency, border color, rotation, format, and line thickness.
- Navigate one page at a time or view multiple pages; zoom into specific areas.

### Annotation and forms

- Draw, highlight, erase, and mark up a PDF.
- Choose multiple annotation colors and line widths.
- Fill out an existing PDF.
- Create a fillable PDF form.
- Add or edit form fields.
- Flatten fields and annotations when the final document should be less editable.

### Watermarks and overlays

- Add a text or image watermark.
- Combine text and image in one watermark.
- Set watermark font, size, bold/italic/underline, color, opacity, orientation, and position.
- Scale or rotate a watermark.
- Place a watermark above or below document content.
- Tile a watermark across a page.
- Apply it to every page or only selected pages.
- Overlay one PDF onto another PDF.

## 9. Optimize, compress, repair, and rasterize

### Compression

- Reduce PDF file size while attempting to maintain useful quality.
- Select extreme, high, or regular compression levels where offered.
- Compare original size and percentage reduction after processing.
- Already optimized PDFs may not compress further.
- Batch-compress multiple files.

### Optimization and rendering

- Web-optimize a PDF for faster web delivery.
- Rasterize PDF pages into image-based page content.
- Flatten text, images, annotations, layers, form fields, or markups into a final-looking document.
- Improve print compatibility and reduce the ability to edit interactive elements.

### Repair and OCR

- Analyze damaged or corrupt PDFs and attempt to repair or recover their content.
- OCR scanned PDFs and create searchable/extractable text.
- Use OCR as a preprocessing step for bank statements and other scanned records.

## 10. Security, privacy, and document control

- Protect a PDF with a password.
- Encrypt a PDF and apply permission restrictions.
- Unlock a PDF by removing a password or restrictions where the supplied file/password permits it.
- Redact sensitive information permanently so it cannot be recovered by ordinary editing or copying.
- Remove PDF metadata such as author/application information.
- Generate a password for PDF protection.
- Remove a white box from a handwritten signature and create a transparent reusable signature PNG.
- Change PDF document information/metadata.
- Set PDF viewer preferences.
- Add bookmarks for navigation.

### Privacy models observed

- Some Drawboard tools process entirely in the browser, keep files on the device, offer no cloud sync, and continue working offline after initial load.
- Some iLovePDF tools upload temporarily, support automatic deletion, and can save results back to Google Drive or Dropbox.
- Adobe conversion pages displayed HTTPS/TLS 1.2/AES-256 security messaging and stated that files are deleted unless the user signs in.
- Smallpdf pages referenced TLS, GDPR, ISO 27001, and automatic deletion for selected tools.
- pdf.net pages advertised HTTPS/encryption, private files, no long-term storage for selected AI tools, and no model training for Markdown conversion.

## 11. Sign, send, and share

### Sign locally or in-browser

- Add a typed, drawn, or uploaded signature.
- Add signature date and initials fields.
- Sign PDF, office documents, spreadsheets, and common image formats by converting them as needed.
- Remove the signature background to create a transparent reusable mark.
- Sign from desktop, mobile, or browser without printing.

### Request signatures

- Send a document to multiple recipients.
- Mark where each recipient should sign.
- Invite recipients by email.
- Track signing progress.
- Use a secure document workflow for electronic signatures.

### Share

- Upload a PDF and create a secure link or email share.
- Control whether recipients can view or edit.
- Cancel the validity of a download/share link where supported.

## 12. View, compare, and inspect

- View PDFs online, print them, and share them.
- Use a dedicated PDF reader on desktop or in the browser.
- Compare two PDFs side by side or as an overlay.
- Detect added, deleted, or replaced lines.
- Set viewer preferences.
- Preview pages before merge, split, extract, delete, watermark, or reorder operations.

- Chat with a PDF by asking questions about names, dates, figures, facts, and details.
- Ask follow-up questions after receiving a summary.
- Summarize PDFs, Word files, Excel files, PowerPoint files, and images.
- Produce key takeaways, notes, and chapter-style summaries.
- Generate a concise text summary.
- Translate a PDF in 20+ languages.
- Request either a summary translation or a full translation.
- Generate multiple-choice, true/false, or open-ended questions from document content.
- Generate flashcards, quizzes, mind maps, and presentations from document content.
- Build an AI-assisted resume.
- Use a general PDF AI assistant for document questions and processing.

## 14. Workflow, platform, and file-handling features

- Upload by file picker or drag and drop.
- Select multiple files with Ctrl/Shift or by dragging them onto the workspace.
- Import directly from Google Drive or Dropbox and save processed results back to those services.
- Sort uploaded files alphabetically or in reverse alphabetical order.
- Add more files, remove files, rotate them, or reorder them after upload.
- Process one file, many files, or repeated batches depending on the tool.
- Use browser tools on desktop, tablet, and mobile.
- Use dedicated desktop applications for PDF creation, printing, reading, compression, merging, splitting, conversion, and editing.
- Use mobile apps for scanning, editing, converting, and signing.
- Use local/offline processing where the page advertises it.
- Download a single result, several individual results, or a ZIP archive.
- Output files may be deleted from remote servers after a retention period; the exact period varies by service/account.
- Processing speed depends on file size and connection when a service uses upload-based processing.
