# Workstream E AI fallback fixture

This synthetic fixture represents ten extracted document pages. It is deliberately plain text so the
local summarizer can be tested without a provider, model download, or network call.

## Page 1 — Scope

Document governance defines review obligations and the people responsible for approving a change.

## Page 2 — Context

The operating context describes the records, dates, and assumptions that a reviewer must verify.

## Page 3 — Risk

Risk review records an owner, a mitigation, and the evidence needed before a decision is accepted.

## Page 4 — Privacy

Private document bytes remain local unless a user explicitly confirms a configured external request.

## Page 5 — Accessibility

Accessible output needs readable order, useful headings, and an honest description of missing structure.

## Page 6 — Security

Security controls prevent secrets from entering URLs, recipes, logs, diagnostics, or generated artifacts.

## Page 7 — Cost

An external request shows a character and token estimate before the user confirms the action.

## Page 8 — Recovery

Unsupported capabilities return a typed remedy and preserve the original document for another attempt.

## Page 9 — Review

Every generated or translated result is reviewable before export and never presented as verified fact.

## Page 10 — Completion

The final gate records tests, limitations, and the exact boundary between local and user-invoked work.
